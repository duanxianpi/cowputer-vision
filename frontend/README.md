# README

## Getting Started

### Requirement

| Requirement | Version |
| - | - |
| Node.js | v20.9.0 (LTS) |

It is recommended to use [nvm](https://github.com/nvm-sh/nvm) to manage Node.js versions.

### Compile and Run
1. Install the dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Understanding the Codebase
The codebase is structured as follows:
- `frontend/`: Contains the source code of the whole Next.js frontend.
  - `api/`: API clients and setup for making HTTP requests to the backend.
  - `app/`: Next.js application files, including pages and layouts.
    - `auth/`: Authentication-related pages and components.
    - `dashboard/`: Dashboard-related pages and components.
    - `components/`: Reusable UI components.
    - `hooks/`: Custom React hooks for state management, side effects and API calls.
    - `services/`: Services that directly interact with the backend API.

## API Calling Structure
The frontend interacts with the backend API through a structured approach:
1. **API Clients**: Located in the `api/client.ts`, this file is generated by `openapi-zod-client` and contains functions for making HTTP requests to the backend API endpoints.
2. **Services**: Located in the `services/` directory, these files contain functions that call the API clients and handle any necessary data.
3. **Hooks**: Located in the `hooks/` directory, these files contain custom React hooks that utilize `react-query` to manage data fetching, caching, and state management for API calls.
